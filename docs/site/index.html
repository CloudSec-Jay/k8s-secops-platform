The brief

The goal is not simply to make Wazuh pods healthy. The system needs an explainable path from a Linux endpoint, through a controlled network boundary, into searchable evidence and an operator response.

This repository joins the kubeadm platform, Cilium policy, Hubble visibility, portable Wazuh content, and recovery guidance without hiding the work that still needs target-cluster validation.

Persistent evidence / backup and restore boundary

Cilium starts from isolation and preserves DNS deliberately. Hubble exposes the resulting flows so policy can be built from observed behavior instead of assumptions.

Wazuh receives endpoint events, applies reviewed rules and decoders, retains searchable security data, and gives the operator a place to investigate.
